# سایت شناخت زمین دارآباد

تهیه و ارائه: ماهان اصلانی

## باز کردن نسخه‌ی محلی
فایل index.html را باز کنید. پوشه‌ی assets و بقیه‌ی فایل‌ها باید کنار آن بمانند.

## انتشار روی GitHub Pages
۱. فایل ZIP را استخراج کنید؛ خود ZIP را برای نمایش سایت بارگذاری نکنید.
۲. تمام محتویات این پوشه را در ریشه‌ی مخزن GitHub قرار دهید؛ index.html باید مستقیماً در ریشه باشد، نه داخل یک پوشه‌ی اضافی.
۳. در Settings → Pages، بخش Source را روی Deploy from a branch بگذارید.
۴. شاخه‌ی main و مسیر /(root) را انتخاب و Save کنید. ساخت سایت چند دقیقه زمان می‌برد.
۵. دامنه‌ی خود را در همان صفحه، قسمت Custom domain وارد و ذخیره کنید. در صورت نیاز DNS دامنه را مطابق راهنمای رسمی GitHub تنظیم کنید و پس از آماده‌شدن گواهی، Enforce HTTPS را فعال کنید.

فایل CNAME برای دامنه‌ی mahandoesthings.info همراه بسته است؛ هنگام به‌روزرسانی مخزن آن را حفظ کنید.

این سایت ایستا است؛ نصب پکیج، سرور اختصاصی و مرحله‌ی build لازم ندارد. مسیر فایل‌ها نسبی است و برای دامنه‌ی اختصاصی یا زیرمسیر مخزن مناسب است.

## رسانه‌ها
دو ویدیوی تابستانی و ضبط متحرک باد به MP4 بی‌صدا تبدیل شده‌اند. ویدیوها هنگام ورود به محدوده‌ی دید پخش می‌شوند و کنترل توقف دارند. تنظیم کاهش حرکت سیستم محترم شمرده می‌شود. نسخه‌ی ۶ تا ۱۵ کمی آهسته‌تر پخش می‌شود تا بیش از پنج ثانیه طول بکشد؛ فریم‌های تحلیل حفظ شده‌اند.
فونت ب نازنین همراه فایل‌هاست. فایل‌های اصلی حجیم AVI و فایل‌های کاری CAD در بسته‌ی انتشار قرار نگرفته‌اند.


## نسخه‌ی تکمیل‌شده ۱۳ اکتبر ۲۰۲۶
ویدیوی زمستان، شواهد میدانی و چهار دیاگرام نتیجه‌گیری اضافه شده‌اند. جانمایی‌ها مفهومی و مشروط به حریم برق و کنترل ترازند. برای به‌روزرسانی سایت موجود، index.html و پوشه‌ی assets را با این نسخه جایگزین و CNAME را حفظ کنید.


## به‌روزرسانی ۱۴ اکتبر ۲۰۲۶
نقشه‌ی پایه‌ی CAD/Rhino، مبنای شمال و کنترل اندازه‌ها و تقویم فرضی استفاده اضافه شد. چارچوب نتیجه‌گیری، معیارهای تکلیف بعدی است.
